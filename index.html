About Me

I’m a Cloud Native Security Architect based in Miami, FL. I design and secure systems across AWS and GCP, with a focus on DevSecOps, AI-driven workflows, and Kubernetes-based infrastructure.

My approach is simple: security should be built into the system, not added later. I work hands-on with Kubernetes, Terraform, ArgoCD, and Cilium to implement real-world security patterns in live environments. I hold CISSP, CKA, CKAD, AWS Solutions Architect, and CCSK certifications.

I write about cloud security, homelab experiments, and breaking into the field at blog.herreralab.cloud.
